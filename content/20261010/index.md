# PA Script Generation System
For years, I've been using Google Sheets to generate PA scripts. I've reenvisioned that process as a web app. Rosters are fetched from the web. Then you can upload a Word roster, and AI tries to fill in any missing info, things like pronunciations and how many years the head coach has been there.  The app generates the script, and then you can use the teleprompter view to read it live. It also generates a printable version of the rosters for the score table.
